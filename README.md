# google-play-store-eda-assignment
Exploratory Data Analysis of Google Play Store apps using Python, Pandas, Matplotlib and Seaborn.
# Google Play Store Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Google Play Store dataset to understand app ratings, reviews, installations, pricing, and categories.

## Objectives
- Understand the dataset and its attributes.
- Clean and preprocess the data.
- Analyze app ratings, reviews, installations, and prices.
- Compare free and paid applications.
- Visualize patterns and summarize useful insights.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Files
- `google playstore.ipynb` — EDA code and visualizations.
- `googleplaystore_cleaned.csv` — Cleaned dataset.
- EDA report PDF — Analysis, findings, and recommendations.
- EDA presentation PPTX — Project presentation.

## Key Findings
- The dataset contains approximately 10,358 records after the project's preprocessing.
- The average app rating is approximately 4.21.
- The FAMILY category is the most common category in the analyzed dataset.
- Free apps make up approximately 92.61% of the analyzed apps.

## Conclusion
The analysis explores patterns in app ratings, reviews, installations, pricing, and categories to identify trends and recommendations for app developers.
